Rocket art:

  Porcini base image.png

Typical Windows path:

  C:\Porchini Racer\Art\Porcini base image.png

The game loads this as the mushroom rocket (cap = nose right, flames left).
Transparent PNG — no white/checkerboard background. Built-in flames are used;
extra particle flames only kick in while boosting.

To replace: drop a new transparent PNG with the same filename and restart the
dev server (Ctrl+F5 in the browser).
