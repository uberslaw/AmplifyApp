# Mushroom Blaze

Side-scrolling racer: ride a flaming giant mushroom through rainbow gates of shifting sizes, shapes, patterns, and speeds.

## Play

```bash
cd mushroom-racer
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

```bash
npm run build   # production bundle in dist/
npm run preview # serve the build
```

## Controls

| Input | Action |
|---|---|
| `W` / `S` or `↑` / `↓` | Steer up / down |
| `Space` / `D` / `→` | Boost |
| `P` / `Esc` | Pause |
| Touch drag | Steer |
| Touch right side | Boost |

Clear gates to score. Hit a frame or miss the opening and the run ends. Best score is saved in the browser.
